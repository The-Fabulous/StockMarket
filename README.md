# StockMarket

Локальный сайт биржи фриланса с аукционами на понижение. Заказчики публикуют задачи, исполнители предлагают цену ниже текущей, а заказчик выбирает подходящего исполнителя.

## Запуск

Нужен Node.js 20 или новее. Дополнительные зависимости не требуются.

```powershell
cd "C:\Users\letsp\OneDrive\Desktop\The Fabulous\StockMarket"
npm start
```

Открыть http://127.0.0.1:3210. Для другого порта задайте переменную `PORT`.

Или запустите `start.cmd` двойным щелчком и оставьте окно сервера открытым.

## Что работает

- Регистрация и вход по логину и паролю. Вход можно пропустить: гость видит заказы и историю ставок.
- Демонстрационный аккаунт: логин `demo`, пароль `stockmarket`. В нём можно оставлять ставки и публиковать заказы.
- Категории, поиск по тексту и навыкам, сортировка, избранное, свои предложения и свои заказы.
- Карточка заказа с описанием, графиком снижения цены, полной историей ставок и формой предложения.
- Публикация заказов, проверка бюджета и сроков, выбор исполнителя и закрытие приёма ставок.
- Проверка ставок на сервере: положительное целое число строго ниже последней ставки; нельзя ставить на свой заказ или завершённый аукцион.
- Автоматическое обновление заказов и истории каждые 15 секунд.
- Адаптивная мобильная версия, доступные формы, управление диалогами с клавиатуры.

## Хранение и границы версии

Приложение слушает только `127.0.0.1`, доступно на этом компьютере и не опубликовано в интернете. Данные аккаунтов, заказов и ставок сохраняются в `.local/database.json`. Пароли хешируются с индивидуальной солью через scrypt. Сессии хранятся в памяти сервера, cookie имеет HttpOnly и SameSite=Strict; после перезапуска потребуется снова войти. Избранное хранится в браузере.

Шесть стартовых заказов и их исходные ставки — демонстрационные примеры, отмеченные в интерфейсе. Примерные заказчики не имеют паролей и не могут войти. Реальные платежи, переписка, доставка работы, восстановление пароля и внешние уведомления не подключены. Для общего доступа нужен отдельный этап развёртывания с HTTPS, промышленной базой данных и настройкой управления аккаунтами.

`STOCKMARKET_DATA_DIR` задаёт отдельный каталог данных, например для тестов. Не размещайте `.local` в публичном каталоге.

## Проверки

```powershell
npm run check
npm test
```

Автотесты запускают изолированный сервер и проверяют регистрацию, вход, сохранение данных, защиту маршрутов, ограничения ставок, конкурентные предложения и выбор исполнителя. Рабочие данные не затрагиваются.
